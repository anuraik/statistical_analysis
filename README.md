# statistical_analysis
Analysing different data sets by using regression, T-test and chi-square statistic.

#1 Advertising cost 

🎯 Business Question

How much does advertising cost affect sales?

🛠️ Tools
- Excel

📊 Analysis

The analysis examined data set, which contains advertaising cost and sales revenue.  Time period is over 68 months. 

From Table Advertising (€) and Revenue from Sales (€) we can see that there is no direct relationship over time. There have been some fluctuations in sales revenue, but they does not seem to have been a direct increase over time. 

Next, let's look at how advertising and sales revenue are related from Advertising (€) vs Revenue from Sales (€) table. Correlation coefficient is 0,953, which means very strong positive connection between advertising cost and sales revenue. From regression equation, we can see that for every 1€ spent on advertising, there is an increase of 4,86€ in revenue. We can also see that if advertising cost were 0€, then sales revenue would still be 28 952€.

Also, let´s look how likely it is that the results we got are not just the result of random variation but are real differences. For that we use statistical analysis. Confidence level is 95%. Significance is 0, which shows that there is a very small probability that we have no relationship. The model is statistically significant. We also look at the upper and lower 95%. This shows that there is a 95% chance that these sales revenue changes will fall between 4.59 and 5.12. This gives us a range where the actual value could lie.

These results can be interpreted in several ways. One explanation is that higher advertising cost also leads to higher sales revenue. Another explanation is that  advertising cost and sales revenue have both increased over time with economic growth.

#2 Parcel robots

🎯 Business Question

Is a parcel robot with new software faster on average than a parcel robot with old software?

🛠️ Tools
- Excel

📊 Analysis

For this analysis, T-test was used, to measure statistical significance. 
The average delivery time for the old delivery robots was 4.99, and 4.68 with the new software. The difference is also statistically significant (t-statistic value 7.75, 598 degrees of freedom, and p-value < 0.01).

#3 Marketing

🎯 Business Question

Do more sign-ups come from one advertising channel?

🛠️ Tools
- Excel

📊 Analysis

Chi-square statistic was used for this analysis. It was used to determine whether the difference is statistically significant. 
49% of people coming from Facebook ads and 53% of those coming via the newsletter joined the program, but this difference was not statistically significant (chi-square statistic 2.04, degrees of freedom 1, and p-value = 0.15).
